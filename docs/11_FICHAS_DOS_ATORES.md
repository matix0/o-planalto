Este documento consolida o perfil detalhado de cada um dos 24 atores do jogo, incluindo arquétipo, aparência, voz, motivação, medo, o que oferece, o que cobra, cartas associadas, eventos encadeados, citações de referência e fundamentação teórica. É o documento-base para os roteiristas escreverem as cartas de cada ator.

## 11.1. Fundamentação Teórica sobre Atores

### 11.1.1. Por Que Personagens São Essenciais em Jogos Educativos

Personagens são essenciais em jogos educativos por três razões:

1. **Identificação** — o jogador se conecta com personagens, não com conceitos abstratos.
2. **Memorização** — personagens marcantes são lembrados mais facilmente que dados.
3. **Humanização** — personagens dão rosto a forças sociais e políticas.

> "Um personagem bem construído é uma ideia encarnada." — Robert McKee, *Story*

### 11.1.2. Metodologia de Construção dos Atores

Cada ator foi construído com base em:

| Fonte | Contribuição |
| :--- | :--- |
| **História do Brasil** | Cada ator é herdeiro de um tipo social histórico |
| **Ciência política** | Cada ator representa uma força política real |
| **Psicologia** | Cada ator tem motivações e medos identificáveis |
| **Literatura** | Cada ator tem uma voz própria, inspirada em arquétipos |
| **Comentários do Professor Alisson** | Cada ator oferece recompensas em medidores específicos |
