
**Como usar no jogo:** O ciclo é aplicado em cada decisão: o jogador arrasta a carta (experiência), vê a consequência (observação), lê a Carta de Aprendizado (conceituação) e aplica na próxima decisão (experimentação).

### 06.12.3. Mihaly Csikszentmihalyi

**Mihaly Csikszentmihalyi** desenvolveu a **Teoria do Flow**, que defende que o engajamento máximo ocorre quando o desafio é compatível com a habilidade.

**Como usar no jogo:** A curva de dificuldade progressiva (Lua de Mel → Realidade Bate → Crise → Desfecho) mantém o jogador no "canal de fluxo".

### 06.12.4. Lev Vygotsky

**Lev Vygotsky** desenvolveu a **Zona de Desenvolvimento Proximal (ZDP)**, que defende que o aprendizado ocorre quando o desafio está ligeiramente acima do nível atual do aluno.

**Como usar no jogo:** Os desafios são progressivos, mas alcançáveis. O jogador é desafiado a ir além do que já sabe.
