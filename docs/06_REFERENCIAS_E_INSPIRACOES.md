## 06.02 — Jogos de Cartas e Simulação

### 06.02.1. Reigns (Nerial, 2016)

| Campo | Valor |
| :--- | :--- |
| **Nome** | Reigns |
| **Desenvolvedora** | Nerial |
| **Publicadora** | Devolver Digital |
| **Criador** | François Alliot |
| **Lançamento** | 11 de agosto de 2016 |
| **Plataformas** | iOS, Android, PC, Nintendo Switch |
| **Gênero** | Estratégia / Narrativa / Escolhas |

**O que é:**

Reigns é um jogo de estratégia minimalista onde o jogador assume o papel de um monarca que toma decisões arrastando cartas para a esquerda (recusar) ou direita (aceitar). Cada decisão afeta **quatro medidores** (Igreja, Povo, Exército, Tesouro). Se qualquer medidor chegar a zero, o reinado termina.

**Como funciona:**

| Elemento | Descrição |
| :--- | :--- |
| **Interação por Swipe** | Inspirada no Tinder. Cada decisão é uma carta. |
| **Quatro Pilares de Poder** | Igreja, Povo, Exército e Tesouro. |
| **Consequências Extremas** | Se qualquer indicador chegar a zero, o reinado termina. |
| **Narrativa Adaptativa** | As cartas aparecem conforme o estado do reino. |
| **Morte e Renascimento** | Cada morte desbloqueia novas cartas. |

**Como usar no jogo:**

| Aplicação | Descrição |
| :--- | :--- |
| **Mecânica central** | O jogo usa a mesma mecânica de arrastar cartas para esquerda/direita. |
| **Sistema de cartas** | O "saco de cartas" que aumenta e diminui conforme o estado do reino inspira o nosso sistema de sorteio. |
| **Consequências em 4 pilares** | O design de "consequências em 4 pilares" é expandido para 8 medidores no nosso jogo. |
| **Filosofia de simplicidade** | Um gesto simples controla um jogo complexo. |

**Fundamentação Teórica:**

> "Assim que ponderamos as decisões do jogador com consequências nas 4 dimensões de poder, demos muito significado a gestos muito simples de deslizar." — François Alliot, criador de *Reigns*

**Referências:**

- NERIAL. *Reigns*. 2016. Devolver Digital.
- ALLIOT, François. *Reigns: Design Philosophy*. 2016.

Senhor Presidente é um simulador de presidência da República onde o jogador assume o papel do primeiro presidente democraticamente eleito da fictícia **República do Bananistão**. O objetivo é sobreviver ao mandato de 4 anos.

**Como funciona:**

| Herança | Descrição |

## 06.03 — Jogos Educativos

### 06.03.1. IAgora? (Politize! / Lupa / AppCívico, 2024)

| Campo | Valor |
| :--- | :--- |
| **Nome** | IAgora? |
| **Desenvolvedores** | Politize!, Agência Lupa, AppCívico |
| **Lançamento** | 2024 |
| **Plataformas** | Web |
| **Gênero** | Jogo educativo / Combate à desinformação |

**O que é:**

IAgora? é um jogo online desenvolvido pela Politize! em parceria com a Agência Lupa e o AppCívico, lançado durante as eleições municipais de 2024. O objetivo é treinar eleitores para identificar e combater técnicas de desinformação.

**Como funciona:**

O jogo simula o ambiente de uma campanha eleitoral, mas com uma inversão interessante: o jogador assume o papel de **agente de desinformação**, usando técnicas como deepfakes e manipulação de narrativas para tentar vencer a eleição. A ideia é baseada na **"teoria da inoculação"**.

**Como usar no jogo:**

| Aplicação | Descrição |
| :--- | :--- |
| **Estrutura do Modo Influenciador** | As cartas do nosso jogo podem simular situações onde o jogador é exposto a narrativas manipuladas e precisa decidir como reagir. |
| **Modelo de parceria** | A colaboração entre uma organização de educação política (Politize!), um veículo de checagem (Lupa) e uma empresa de tecnologia cívica (AppCívico) demonstra um modelo viável. |
| **Teoria da inoculação** | A exposição controlada a técnicas de manipulação desenvolve resistência psicológica. |

**Fundamentação Teórica:**

> "A inoculação funciona como uma vacina: ao ser exposto a uma versão enfraquecida da manipulação, o indivíduo desenvolve anticorpos contra ela." — William McGuire

**Referências:**

- POLITIZE!, LUPA, APPCÍVICO. *IAgora?* 2024.
- MCGUIRE, William. *Resistance to Persuasion*. 1964.
- VAN DER LINDEN, Sander. *Inoculation Theory*. 2022.
- COOK, John; LEWANDOWSKY, Stephan; ECKER, Ullrich. *Misinformation and How to Correct It*. 2017.

## 06.04 — Ferramentas de Educação Política

### 06.04.1. Bússola 2026

| Campo | Valor |
| :--- | :--- |
| **Nome** | Bússola 2026 |
| **Tipo** | Ferramenta de bússola eleitoral |
| **Lançamento** | 2026 |
| **Plataforma** | Web |

**O que é:**

A Bússola 2026 é uma ferramenta de "bússola eleitoral" brasileira, lançada para as eleições de 2026. Ela contém **12 perguntas** sobre temas que coincidem com os eixos dos nossos medidores: economia, segurança, saúde, educação, meio ambiente, política externa, instituições e costumes.

**Como funciona:**

O usuário responde a 12 afirmações, posicionando-se em uma escala (concordo totalmente, concordo parcialmente, discordo parcialmente, discordo totalmente). O sistema então calcula a **distância** entre suas respostas e a posição de cada candidatura, com **peso dobrado** nos temas que o usuário marcar como decisivos.

**Como usar no jogo:**

| Momento | Aplicação |
| :--- | :--- |
| **Calibração Inicial** | 6 perguntas (uma para cada medidor) definem os valores iniciais personalizados. |
| **Calibração Final** | Gráfico de afinidade entre o "país construído" e os cenários políticos gerados. |

**Fundamentação Teórica:**

Ferramentas de bússola eleitoral são baseadas na **teoria da proximidade espacial** (spatial proximity theory), que defende que os eleitores votam no candidato mais próximo de suas posições ideológicas.

**Referências:**

- BÚSSOLA 2026. *Ferramenta de bússola eleitoral*. 2026.
- DOWNS, Anthony. *An Economic Theory of Democracy*. New York: Harper & Row, 1957.

## 06.05 — Testes de Espectro Político

### 06.05.1. 9axes

| Campo | Valor |
| :--- | :--- |
| **Nome** | 9axes |
| **Tipo** | Teste de espectro político |
| **Eixos** | 9 |
| **Plataforma** | Web |

**O que é:**

O 9axes é um teste de espectro político com múltiplos eixos. Ele permite uma representação **multidimensional** do espectro político, evitando a dicotomia simplista esquerda-direita.

**Como funciona:**

O 9axes divide o espectro político em **9 eixos**:

| Eixo | Extremo A | Extremo B |
| :--- | :--- | :--- |
| **Economia** | Coletivismo | Mercado |
| **Diplomacia** | Nacionalismo | Globalismo |
| **Sociedade** | Conservadorismo | Progressismo |

## 06.06 — Teorias Pedagógicas e de Design

### 06.06.1. Pedagogia da Libertação (Paulo Freire)

| Campo | Valor |
| :--- | :--- |
| **Nome** | Pedagogia da Libertação |
| **Autor** | Paulo Freire |
| **Obra** | *Pedagogia do Oprimido* (1968) |

**O que é:**

A Pedagogia da Libertação é um método pedagógico que busca a conscientização e a libertação do oprimido. Freire critica a **"educação bancária"** — o modelo tradicional em que o aluno é um receptáculo passivo de conhecimento — e propõe uma educação **dialógica**.

**Como funciona:**

| Conceito | Descrição |
| :--- | :--- |
| **Educação Bancária** | Modelo tradicional em que o aluno é receptáculo passivo |
| **Educação Dialógica** | Educador e educando aprendem juntos |
| **Conscientização** | Processo de tomada de consciência da realidade |
| **Práxis** | Reflexão e ação transformadora |

**Como usar no jogo:**

| Aplicação | Descrição |
| :--- | :--- |
| **Base pedagógica** | O jogo não ensina por transmissão, mas por **experiência dialógica**. |
| **Cartas de Aprendizado** | O jogador não decora conceitos; ele os vivencia e reflete sobre eles. |
| **Tom do jogo** | A comunicação é dialógica, não bancária. |

**Fundamentação Teórica:**

> "A educação não transforma o mundo. Educação muda as pessoas. Pessoas transformam o mundo." — Paulo Freire

> "Ninguém liberta ninguém, ninguém se liberta sozinho: os homens se libertam em comunhão." — Paulo Freire

**Referências:**

- FREIRE, Paulo. *Pedagogia do Oprimido*. Rio de Janeiro: Paz e Terra, 1968.

---

### 06.06.2. Aprendizagem Experiencial (David Kolb)

| Campo | Valor |
| :--- | :--- |
| **Nome** | Aprendizagem Experiencial |
| **Autor** | David Kolb |
| **Obra** | *Experiential Learning* (1984) |

**O que é:**

A Aprendizagem Experiencial é uma teoria que defende que o aprendizado ocorre em um **ciclo de quatro etapas**: Experiência Concreta → Observação Reflexiva → Conceituação Abstrata → Experimentação Ativa.

**Como funciona:**

| Etapa | O que acontece |
| :--- | :--- |
| **Experiência Concreta** | O jogador arrasta a carta |
| **Observação Reflexiva** | Ele vê a consequência |
| **Conceituação Abstrata** | Ele lê a Carta de Aprendizado |
| **Experimentação Ativa** | Ele aplica o que aprendeu na próxima decisão |

**Como usar no jogo:**

| Aplicação | Descrição |
| :--- | :--- |
| **Estrutura das Cartas de Aprendizado** | O ciclo de Kolb é aplicado em cada decisão. |
| **Design do jogo** | O jogo é estruturado para que o jogador vivencie, reflita, conceitue e experimente. |

**Fundamentação Teórica:**

O ciclo de Kolb é a base da **aprendizagem experiencial**, que defende que o conhecimento é construído a partir da experiência.

**Referências:**

- KOLB, David. *Experiential Learning: Experience as the Source of Learning and Development*. Englewood Cliffs: Prentice-Hall, 1984.

---

### 06.06.3. Teoria do Flow (Mihaly Csikszentmihalyi)

| Campo | Valor |
| :--- | :--- |
| **Nome** | Teoria do Flow |
| **Autor** | Mihaly Csikszentmihalyi |
| **Obra** | *Flow: The Psychology of Optimal Experience* (1990) |

**O que é:**

A Teoria do Flow defende que o engajamento máximo ocorre quando o desafio é **compatível com a habilidade**. Se o desafio é muito fácil, o jogador entedia; se é muito difícil, ele abandona.

**Como funciona:**

| Estado | Desafio vs. Habilidade |
| :--- | :--- |
| **Tédio** | Desafio < Habilidade |
| **Flow** | Desafio = Habilidade |
| **Ansiedade** | Desafio > Habilidade |

**Como usar no jogo:**

| Aplicação | Descrição |
| :--- | :--- |
| **Curva de dificuldade** | A progressão em 4 fases (Lua de Mel → Realidade Bate → Crise → Desfecho) mantém o jogador no "canal de fluxo". |
| **Balanceamento** | O jogo não deve ser frustrante a ponto de afastar o jogador. |

**Fundamentação Teórica:**

> "O flow é o estado de imersão total. Ele ocorre quando o desafio é nem muito fácil nem muito difícil." — Mihaly Csikszentmihalyi

**Referências:**

- CSIKSZENTMIHALYI, Mihaly. *Flow: The Psychology of Optimal Experience*. New York: Harper & Row, 1990.

---

### 06.06.4. Zona de Desenvolvimento Proximal (Vygotsky)

| Campo | Valor |
| :--- | :--- |
| **Nome** | Zona de Desenvolvimento Proximal (ZDP) |
| **Autor** | Lev Vygotsky |
| **Obra** | *A Formação Social da Mente* (1984) |

**O que é:**

A Zona de Desenvolvimento Proximal é a **distância entre o que o aluno já sabe e o que ele pode aprender com ajuda**. O aprendizado ocorre quando o desafio está ligeiramente acima do nível atual do aluno.

**Como funciona:**

| Nível | Descrição |
| :--- | :--- |
| **Zona de Conforto** | O que o aluno já sabe |
| **Zona de Desenvolvimento Proximal** | O que o aluno pode aprender com ajuda |
| **Zona de Frustração** | O que o aluno não consegue aprender |

**Como usar no jogo:**

| Aplicação | Descrição |
| :--- | :--- |
| **Progressão** | Os desafios são progressivos, mas alcançáveis. |
| **Cartas de Aprendizado** | O jogo fornece o suporte necessário para o jogador aprender. |

**Fundamentação Teórica:**

A ZDP é a base da **aprendizagem mediada**, que defende que o aprendizado é um processo social.

**Referências:**

- VYGOTSKY, Lev. *A Formação Social da Mente*. São Paulo: Martins Fontes, 1984.

### 06.06.5. Scaffolding (Wood, Bruner e Ross)

| Campo | Valor |
| :--- | :--- |
| **Nome** | Scaffolding (Andaime) |
| **Autores** | David Wood, Jerome Bruner, Gail Ross |
| **Artigo** | *The Role of Tutoring in Problem Solving* (1976) |

**O que é:**

O Scaffolding é uma teoria que defende que o aprendizado é facilitado quando o educador fornece **suporte temporário** que é gradualmente removido conforme o aluno ganha autonomia.

**Como funciona:**

| Fase | Suporte |
| :--- | :--- |
| **Início** | Muito suporte (instruções detalhadas) |
| **Meio** | Suporte moderado (dicas) |
| **Fim** | Nenhum suporte (autonomia) |

**Como usar no jogo:**

| Aplicação | Descrição |
| :--- | :--- |
| **Fases do jogo** | Cada fase fornece o suporte necessário para a próxima. |
| **Cartas de Aprendizado** | O suporte é gradualmente removido conforme o jogador aprende. |

**Fundamentação Teórica:**

O Scaffolding é a base da **aprendizagem assistida**, que defende que o educador deve fornecer o suporte necessário para o aluno avançar.

**Referências:**

- WOOD, David; BRUNER, Jerome; ROSS, Gail. *The Role of Tutoring in Problem Solving*. Journal of Child Psychology and Psychiatry, 1976.
