## 18.01 — Fundamentação Teórica

### 18.01.1. Por Que as Cartas de Aprendizado São Essenciais

As Cartas de Aprendizado são essenciais em jogos educativos por três razões:

1. **Consolidação** — conectam a experiência do jogo com o conhecimento formal.
2. **Reflexão** — incentivam o jogador a pensar sobre o que acabou de vivenciar.
3. **Retenção** — dados e conceitos são mais facilmente lembrados quando conectados a uma experiência emocional.

> "A educação não transforma o mundo. Educação muda as pessoas. Pessoas transformam o mundo." — Paulo Freire

### 18.01.2. Estrutura das Cartas de Aprendizado

Cada Carta de Aprendizado é composta por **5 blocos**:

| Bloco | Conteúdo | Tamanho | Função |
| :--- | :--- | :--- | :--- |
| **1. O que você acabou de vivenciar** | Resumo da decisão tomada | 2 linhas | Conectar a experiência com o conceito |
| **2. O conceito por trás** | Explicação do mecanismo institucional | 3 linhas | Ensinar como o sistema funciona |
| **3. Dados reais** | Números e fatos da realidade brasileira | 3 linhas | Mostrar que o jogo reflete o Brasil |
| **4. Fonte** | Origem dos dados | 1 linha | Dar credibilidade |
| **5. Frase de impacto** | Reflexão final | 1 linha | Memorabilidade |

### 18.01.3. Metodologia de Construção

As Cartas de Aprendizado foram construídas com base em:

| Fonte | Contribuição |
| :--- | :--- |
| **Pesquisas e Estudos (03)** | Dados e citações (a verificar — D-091) |
| **Design do Jogo (04)** | Estrutura dos medidores e cartas |
| **Sistemas e Mecânicas (05)** | Efeitos dos medidores |
| **Guia de Estilo e Tom (10)** | Regras de escrita e tom |
| **Fichas dos Atores (11)** | Vozes e interesses dos atores |
| **Fichas dos Modos (12)** | Contexto de cada modo |

### 18.01.4. Princípios de Escrita

As Cartas de Aprendizado seguem **6 princípios**:

| # | Princípio | Descrição |
| :--- | :--- | :--- |
| 1 | **Clareza** | O jogador deve entender o conceito em menos de 30 segundos |
| 2 | **Precisão** | Os dados devem ser corretos e verificáveis |
| 3 | **Acessibilidade** | Sem jargão acadêmico. Linguagem direta. |
| 4 | **Conexão** | A experiência do jogo deve estar conectada ao conceito |
| 5 | **Impacto** | A frase final deve ser um "soco no estômago" |
| 6 | **Brasilidade** | O texto deve ter a cara do Brasil, sem estereótipos |
