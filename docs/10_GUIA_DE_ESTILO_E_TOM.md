## 10.10. Checklist de Qualidade

### 10.10.1. Para Cartas

| # | Item | ✅ |
| :--- | :--- | :--- |
| 1 | O título tem no máximo 5 palavras? | ☐ |
| 2 | O problema tem no máximo 2 linhas? | ☐ |
| 3 | As opções têm no máximo 1 linha cada? | ☐ |
| 4 | As consequências têm no máximo 1 linha cada? | ☐ |
| 5 | A carta tem uma cor partidária na borda? | ☐ |
| 6 | A carta tem uma Carta de Aprendizado? | ☐ |
| 7 | O texto está na voz ativa? | ☐ |
| 8 | O texto está no presente do indicativo? | ☐ |
| 9 | O texto fala com o jogador (segunda pessoa)? | ☐ |
| 10 | O texto evita jargão acadêmico? | ☐ |

### 10.10.2. Para Cartas de Aprendizado

| # | Item | ✅ |
| :--- | :--- | :--- |
| 1 | O bloco "vivencia" resume a decisão? | ☐ |
| 2 | O bloco "conceito" explica o mecanismo? | ☐ |
| 3 | O bloco "dados" tem números e fatos? | ☐ |
| 4 | O bloco "fonte" cita a origem? | ☐ |
| 5 | A "frase de impacto" é um soco no estômago? | ☐ |
| 6 | O texto está na voz ativa? | ☐ |
| 7 | O texto está no presente do indicativo? | ☐ |
| 8 | O texto fala com o jogador (segunda pessoa)? | ☐ |
| 9 | O texto evita jargão acadêmico? | ☐ |
| 10 | O texto tem no máximo 3 linhas por bloco? | ☐ |

### 10.10.3. Para Finais

| # | Item | ✅ |
| :--- | :--- | :--- |

| 2 | A citação tem no máximo 2 linhas? | ☐ |

| 4 | A citação faz sentido com o final? | ☐ |
