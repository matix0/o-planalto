# 10 — Guia de Estilo e Tom

**Documento de Padronização da Escrita do Jogo "O Planalto"**

Este documento define as regras de estilo, tom, vocabulário e estrutura para a escrita de todas as cartas, Cartas de Aprendizado, diálogos e finais do jogo. O objetivo é garantir consistência, clareza e impacto em todo o conteúdo textual.

---

## 10.01 — Fundamentação Teórica sobre Guias de Estilo

### 10.01.1. Por Que um Guia de Estilo é Essencial

Um guia de estilo é essencial em projetos com grande volume de texto por três razões:

1. **Consistência** — garante que todas as cartas tenham o mesmo tom e formato.
2. **Eficiência** — acelera a escrita, evitando decisões repetitivas.
3. **Qualidade** — estabelece padrões mínimos de clareza e impacto.

> "Um guia de estilo não é uma camisa de força. É um mapa que permite que todos cheguem ao mesmo lugar." — William Strunk Jr., *The Elements of Style*

### 10.01.2. Metodologia de Definição

O guia de estilo foi construído com base em:

| Fonte | Contribuição |
| :--- | :--- |
| **Análise do público-alvo** | Jovens de 15 a 30 anos, periféricos e estudantes |
| **Análise de referências** | *Reigns*, *Senhor Presidente*, Politize!, IAgora? |
| **Pedagogia freiriana** | Linguagem dialógica, não bancária |
| **Design de jogos sérios** | Microlearning, impacto, clareza |
| **Comentários do Professor Alisson** | Linguagem direta, brutal, acessível |

### 10.01.3. Princípios Norteadores

| Princípio | Descrição |
| :--- | :--- |
| **Clareza** | O jogador deve entender a carta em menos de 10 segundos. |
| **Impacto** | Cada carta deve deixar uma marca emocional ou intelectual. |
| **Acessibilidade** | Sem jargão acadêmico. Sem rebuscamento. |
| **Humanidade** | O texto deve soar como uma conversa, não como um manual. |
| **Precisão** | Os dados devem ser corretos e verificáveis. |
| **Brasilidade** | O texto deve ter a cara do Brasil, sem estereótipos. |

### 10.01.4. Referências

- ORWELL, George. *Politics and the English Language*. 1946.
- PINKER, Steven. *The Sense of Style*. New York: Viking, 2014.

## 10.02 — O Tom do Jogo

### 10.02.1. Definição do Tom

O tom do jogo é **direto, humano e levemente irônico**.

| Característica | Descrição | Exemplo |
| :--- | :--- | :--- |
| **Direto** | Sem rodeios. Vai ao ponto. | "O hospital está sem médicos. A população protesta." |
| **Humano** | Fala com o jogador, não para ele. | "Você decide. Mas alguém vai pagar a conta." |
| **Levemente irônico** | Usa ironia sem ser cruel. | "O relator diz que é 'modernização'. O povo chama de venda." |

### 10.02.2. O Que o Tom NÃO É

| O que evitar | Por quê | Exemplo ruim |
| :--- | :--- | :--- |
| **Panfletário** | Afasta quem não concorda | "Vote no PT para salvar o Brasil!" |
| **Acadêmico** | Afasta quem não tem formação | "A conjuntura política contemporânea evidencia..." |
| **Sarcástico cruel** | Ofende o jogador | "Só um idiota escolheria isso." |
| **Derrotista** | Desmotiva o jogador | "Não adianta, tudo vai piorar." |
| **Ufanista** | Soa falso | "O Brasil é o país mais maravilhoso do mundo!" |
| **Neutro demais** | Não engaja | "Há argumentos dos dois lados." |

### 10.02.3. O Tom em Diferentes Contextos

| Contexto | Tom | Exemplo |
| :--- | :--- | :--- |
| **Problema da carta** | Direto, factual | "O Congresso analisa um projeto de privatização." |
| **Opção de esquerda** | Propositivo, social | "Vou investir em programas sociais." |
| **Opção de direita** | Pragmático, individual | "Vou aumentar o policiamento." |
| **Consequência** | Irônico, brutal | "A lei passa. O povo paga a conta." |
| **Carta de Aprendizado** | Didático, acessível | "O relator tem poder de agenda. Quem controla a pauta, controla o país." |
| **Final negativo** | Sombrio, brutal | "O povo é reduzido à mera sobrevivência." |
| **Final positivo** | Esperançoso, mas realista | "Você não mudou o país com decreto. Mudou formando gente que pensa." |

### 10.02.4. Referências

- ORWELL, George. *Politics and the English Language*. 1946.
- THOMPSON, Hunter S. *Fear and Loathing in Las Vegas*. 1971.
- RACIONAIS MC'S. *Sobrevivendo no Inferno*. 1997.

## 10.03 — Regras de Escrita

### 10.03.1. Tamanho dos Textos

| Elemento | Tamanho Máximo | Justificativa |
| :--- | :--- | :--- |
| **Título da carta** | 5 palavras | Legibilidade em mobile |
| **Problema da carta** | 2 linhas (máx. 140 caracteres) | Leitura rápida |
| **Opção (esquerda/direita)** | 1 linha (máx. 60 caracteres) | Cabe no botão |
| **Consequência** | 1 linha (máx. 80 caracteres) | Impacto rápido |
| **Carta de Aprendizado (vivencia)** | 2 linhas | Contexto |
| **Carta de Aprendizado (conceito)** | 3 linhas | Explicação |
| **Carta de Aprendizado (dados)** | 3 linhas | Evidência |
| **Carta de Aprendizado (frase de impacto)** | 1 linha | Memorabilidade |
| **Final (descrição)** | 3 linhas | Síntese |
| **Final (citação)** | 2 linhas | Impacto |

### 10.03.2. Estrutura das Frases

| Regra | Descrição | Exemplo |
| :--- | :--- | :--- |
| **Voz ativa** | Prefira a voz ativa à passiva | ✅ "O Congresso aprova a lei." ❌ "A lei foi aprovada pelo Congresso." |
| **Presente do indicativo** | Use o presente, não o futuro | ✅ "O povo protesta." ❌ "O povo protestará." |
| **Segunda pessoa** | Fale com o jogador | ✅ "Você decide." ❌ "O governante decide." |
| **Frases curtas** | Máximo 20 palavras por frase | ✅ "A lei passa. O povo paga." ❌ "A lei passa e, consequentemente, o povo acaba pagando a conta." |
| **Parágrafos curtos** | Máximo 3 frases por parágrafo | ✅ "O hospital está sem médicos. A população protesta. Você decide." |
| **Evite gerúndio** | Não use "fazendo", "dizendo" | ✅ "Ele diz que é modernização." ❌ "Ele vai dizendo que é modernização." |
| **Evite advérbios** | Não use "muito", "realmente" | ✅ "O povo sofre." ❌ "O povo sofre muito realmente." |

### 10.03.3. Vocabulário

| Categoria | Use | Evite |
| :--- | :--- | :--- |
| **Coloquial** | "cara", "porra", "bagulho" (com moderação) | Gírias datadas ("é o fino", "chuchu beleza") |
| **Técnico** | "impeachment", "orçamento", "bancada" | Jargão desnecessário ("conjuntura", "paradigma") |
| **Brasileiro** | "povo", "periferia", "favela" | Estrangeirismos ("establishment", "deep state") |
| **Direto** | "morte", "fome", "violência" | Eufemismos ("óbito", "insegurança alimentar") |

### 10.03.4. Pontuação

| Regra | Descrição | Exemplo |
| :--- | :--- | :--- |
| **Ponto final** | Use ponto final em frases curtas | "O povo paga a conta." |
| **Reticências** | Use para suspense | "E daí?..." |
| **Travessão** | Use para diálogo | "— Você decide." |
| **Aspas** | Use para citações | "O relator diz que é 'modernização'." |
| **Exclamação** | Use com moderação | "Liberdade ainda que tardia!" |

### 10.03.5. Números

| Regra | Descrição | Exemplo |
| :--- | :--- | :--- |
| **Números arredondados** | Prefira números arredondados | ✅ "R$ 5 bilhões" ❌ "R$ 5.775.432.100,00" |
| **Porcentagens** | Use o símbolo % | ✅ "68% dos eleitores" |
| **Milhares** | Use ponto como separador | ✅ "1.000 jogadores" |
| **Decimais** | Use vírgula como separador | ✅ "R$ 5,7 bilhões" |

### 10.03.6. Referências

- STRUNK, William Jr.; WHITE, E.B. *The Elements of Style*. New York: Macmillan, 1959.
- ORWELL, George. *Politics and the English Language*. 1946.
- PINKER, Steven. *The Sense of Style*. New York: Viking, 2014.

## 10.04 — Como Escrever Cartas

### 10.04.1. Estrutura de uma Carta

```
┌─────────────────────────────────────────┐
│  TÍTULO (5 palavras)                    │
│  [Cor partidária na borda]              │
│                                         │
│  PROBLEMA (2 linhas)                    │
│                                         │
│  ◀ ESQUERDA           DIREITA ▶         │
│  [OPÇÃO A (1 linha)]  [OPÇÃO B (1 linha)]│
│                                         │
│  CONSEQUÊNCIA:        CONSEQUÊNCIA:     │
│  [FRASE CURTA]        [FRASE CURTA]     │
│                                         │
│  CARTA DE APRENDIZADO:                  │
│  [VIVENCIA + CONCEITO + DADOS + FONTE]  │
└─────────────────────────────────────────┘
```

### 10.04.2. O Título

**Regras:**
- Máximo 5 palavras.
- Direto, sem rodeios.
- Deve resumir o dilema.

**Exemplos:**

| ✅ Bom | ❌ Ruim |
| :--- | :--- |
| "Privatização da estatal" | "O dilema da privatização da estatal de energia" |
| "Assaltos aumentaram" | "A questão da segurança pública no bairro" |
| "Emenda para show" | "A polêmica sobre o uso de emendas parlamentares" |

### 10.04.3. O Problema

**Regras:**
- Máximo 2 linhas (140 caracteres).
- Apresenta o dilema sem tomar partido.
- Usa fatos concretos, não opiniões.

**Exemplos:**

| ✅ Bom | ❌ Ruim |
| :--- | :--- |
| "O hospital público está sem médicos. A população protesta." | "O governo é negligente com a saúde pública e a população sofre as consequências." |
| "O Congresso analisa um projeto de privatização. O relator quer mudar o texto." | "Os políticos corruptos querem vender o patrimônio nacional." |
| "Uma seca histórica atinge o Nordeste. O governo precisa agir." | "A seca é um problema natural que o governo não consegue resolver." |

### 10.04.4. As Opções

**Regras:**
- Máximo 1 linha (60 caracteres).
- Cada opção representa uma solução típica de um espectro político.
- Sem rótulos explícitos ("esquerda", "direita").

**Exemplos:**

| Carta | Opção Esquerda | Opção Direita |
| :--- | :--- | :--- |
| Privatização | "Nomear relator adversário" | "Aceitar as mudanças" |
| Assaltos | "Investir em programas sociais" | "Aumentar o policiamento" |
| Saúde | "Investir no SUS" | "Privatizar a gestão" |
| Orçamento | "Taxar grandes fortunas" | "Cortar gastos sociais" |

### 10.04.5. As Consequências

**Regras:**
- Máximo 1 linha (80 caracteres).
- Frase curta, de impacto.
- Pode ser irônica, mas nunca cruel.
- Mostra o resultado da escolha sem julgar.

**Exemplos:**

| Carta | Consequência Esquerda | Consequência Direita |
| :--- | :--- | :--- |
| Privatização | "A lei passa. O povo paga a conta." | "O relator é adversário. O projeto avança." |
| Assaltos | "A comunidade ganhou um centro cultural. Mas a sensação de insegurança continua." | "A polícia ocupa o bairro. As abordagens violentas aumentam." |
| Saúde | "Os médicos voltam. A fila diminui." | "A empresa privada assume. Os ricos são atendidos." |

### 10.04.6. Cores Partidárias

Cada carta tem uma **cor de borda** que sinaliza sua inclinação:

| Cor | Espectro | Quando usar |
| :--- | :--- | :--- |
| **Vermelho** | Esquerda | Carta sobre direitos trabalhistas, assistência social |
| **Azul** | Centro-direita | Carta sobre estabilidade econômica, reformas |
| **Verde** | Agronegócio | Carta sobre agronegócio, meio ambiente |
| **Amarelo** | Centro | Carta sobre governabilidade, negociação |
| **Roxo** | Esquerda radical | Carta sobre movimentos sociais, reforma agrária |
| **Laranja** | Direita liberal | Carta sobre privatização, desregulamentação |
| **Preto** | Extrema-direita | Carta sobre censura, militarização, pânico moral |

### 10.04.7. Referências

- ALLIOT, François. *Reigns: Design Philosophy*. 2016.
- NERIAL. *Reigns: Game Design Document*. 2016.

## 10.05 — Como Escrever Cartas de Aprendizado

### 10.05.1. Estrutura de uma Carta de Aprendizado

| Bloco | Conteúdo | Tamanho |
| :--- | :--- | :--- |
| **1. O que você acabou de vivenciar** | Resumo da decisão | 2 linhas |
| **2. O conceito por trás** | Explicação do mecanismo | 3 linhas |
| **3. Dados reais** | Números e fatos | 3 linhas |
| **4. Fonte** | Origem dos dados | 1 linha |
| **5. Frase de impacto** | Reflexão final | 1 linha |

### 10.05.2. O Bloco 1 — O Que Você Acabou de Vivenciar

**Regras:**
- Resume a decisão tomada.
- Usa segunda pessoa ("Você decidiu...").
- Contextualiza o conceito.

**Exemplos:**

| ✅ Bom | ❌ Ruim |
| :--- | :--- |
| "Você decidiu se aceitava ou não as mudanças do relator." | "A decisão foi tomada." |
| "Você escolheu entre investir no SUS ou privatizar a gestão." | "Você fez uma escolha." |
| "Você decidiu se priorizava a segurança ou a prevenção." | "Você tomou uma decisão." |

### 10.05.3. O Bloco 2 — O Conceito por Trás

**Regras:**
- Explica o mecanismo institucional.
- Usa linguagem acessível.
- Conecta a decisão ao conceito.

**Exemplos:**

| ✅ Bom | ❌ Ruim |
| :--- | :--- |
| "O relator tem poder de alterar o texto de um projeto. Isso se chama 'poder de agenda'." | "O relator detém a prerrogativa regimental de emitir parecer sobre a proposição legislativa." |
| "A dívida pública consome 40% do orçamento. Renegociá-la é uma decisão política." | "A dívida pública é impagável e sua renegociação é um imperativo categórico." |
| "O encarceramento em massa não reduz a violência. Apenas fortalece as facções." | "A política de encarceramento em massa tem se demonstrado ineficaz na redução dos índices de criminalidade." |

### 10.05.4. O Bloco 3 — Dados Reais

**Regras:**
- Apresenta números e fatos da realidade brasileira.
- Usa fontes verificáveis.
- Mostra que o jogo reflete o Brasil.

**Exemplos:**

| ✅ Bom | ❌ Ruim |
| :--- | :--- |
| "A Eletrobras investiu apenas 1/5 do prometido após a privatização. 5 mil concursados foram demitidos." | "A privatização da Eletrobras foi um desastre." |
| "O teto de gastos retirou R$ 37 bilhões do SUS entre 2018 e 2022. A expectativa de vida caiu de 76,2 para 72,8 anos." | "O teto de gastos prejudicou a saúde pública." |
| "A polícia matou 11 pessoas por dia em 2024. 86% eram negras." | "A violência policial é um problema grave no Brasil." |

### 10.05.5. O Bloco 4 — Fonte

**Regras:**
- Cita a origem dos dados.
- Usa fontes confiáveis.
- Formato: Nome da instituição, ano.

**Exemplos:**

| ✅ Bom | ❌ Ruim |
| :--- | :--- |
| "Fonte: Agência Senado, 2026." | "Fonte: internet." |
| "Fonte: IBGE, 2025." | "Fonte: um amigo me disse." |
| "Fonte: CPT, 2025." | "Fonte: não sei." |

### 10.05.6. O Bloco 5 — Frase de Impacto

**Regras:**
- Frase curta, memorável.
- Deve ser um "soco no estômago".
- Pode ser citação de autor ou adaptação.

**Exemplos:**

| ✅ Bom | ❌ Ruim |
| :--- | :--- |
| "O relator tem poder. Quem controla a pauta, controla o país." | "A importância do relator é fundamental no processo legislativo." |
| "Cortar saúde não é 'ajuste fiscal'. É uma escolha que mata." | "Os cortes na saúde têm consequências negativas." |
| "A mentira repetida mil vezes torna-se verdade." | "A desinformação é um problema contemporâneo." |

### 10.05.7. Exemplo Completo de Carta de Aprendizado

```
┌─────────────────────────────────────────────────────────────┐
│  CARTA DE APRENDIZADO                                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  O QUE VOCÊ ACABOU DE VIVENCIAR:                            │
│  Você decidiu se aceitava ou não as mudanças do relator.    │
│                                                             │
│  O CONCEITO POR TRÁS:                                       │
│  O relator tem poder de alterar o texto de um projeto.      │
│  Isso se chama "poder de agenda".                           │
│                                                             │
│  DADOS REAIS:                                               │
│  A Eletrobras investiu apenas 1/5 do prometido após a       │
│  privatização. 5 mil concursados foram demitidos.           │
│                                                             │
│  FONTE: Agência Senado, 2026.                               │
│                                                             │
│  "O relator tem poder. Quem controla a pauta, controla o país."│
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 10.07 — Como Escrever Finais

### 10.07.1. Estrutura de um Final

| Elemento | Tamanho | Exemplo |
| :--- | :--- | :--- |
| **Título** | 2-3 palavras | "Barbárie" |
| **Descrição** | 3 linhas | "O povo é reduzido à mera sobrevivência. A vida não vale nada." |
| **Citação** | 2 linhas | "O povo é o que há de mais reles. Seu destino é ser um carvão humano que se queima na produção." |
| **Autor** | 1 linha | "Darcy Ribeiro" |

### 10.07.2. Regras para Finais

| Regra | Descrição | Exemplo |
| :--- | :--- | :--- |
| **Impacto** | A citação deve ser um "soco no estômago" | ✅ "E daí? Lamento. Quer que eu faça o quê? Eu não sou coveiro." |
| **Precisão** | A citação deve ser correta | ✅ "Liberdade ainda que tardia." ❌ "Liberdade acima de tudo." |
| **Brasilidade** | Prefira autores brasileiros | ✅ Darcy Ribeiro, Paulo Freire, Josué de Castro |
| **Diversidade** | Use autores de diferentes espectros | ✅ Brizola, Freire, Bolsonaro, Hitler |
| **Contexto** | A citação deve fazer sentido com o final | ✅ "Uma mentira repetida mil vezes torna-se verdade." (Desintegração) |

### 10.07.3. Exemplos de Finais

| Final | Citação | Autor |
| :--- | :--- | :--- |
| **Barbárie** | "O povo é o que há de mais reles. Seu destino é ser uma mera força de trabalho, um carvão humano que se queima na produção." | Darcy Ribeiro |
| **Alienação Total** | "A massa não pensa, a massa segue. Quem não pensa, obedece." | MV Bill |

## 10.08 — O Que Evitar

### 10.08.1. Lista de Coisas a Evitar

| O que evitar | Por quê | Exemplo ruim | Como corrigir |
| :--- | :--- | :--- | :--- |
| **Jargão acadêmico** | Afasta o público jovem | "A conjuntura política contemporânea evidencia" | "A política hoje mostra" |
| **Estrangeirismo** | Não é acessível | "O establishment político" | "A elite política" |
| **Eufemismo** | Esconde a realidade | "Insegurança alimentar" | "Fome" |
| **Passividade** | Não engaja | "A lei foi aprovada" | "O Congresso aprovou a lei" |
| **Frases longas** | Cansa o leitor | "A lei passa e, consequentemente, o povo acaba pagando a conta." | "A lei passa. O povo paga." |
| **Advérbios** | Enfraquece o texto | "O povo sofre muito" | "O povo sofre" |
| **Clichês** | Soa falso | "Vamos lutar juntos!" | "Vamos organizar a resistência." |
| **Sarcasmo cruel** | Ofende o jogador | "Só um idiota escolheria isso." | "Essa escolha tem consequências." |
| **Panfletagem** | Afasta quem não concorda | "Vote no PT!" | "Você decide. Mas alguém vai pagar a conta." |
| **Ufanismo** | Soa falso | "O Brasil é o país mais maravilhoso do mundo!" | "O Brasil tem jeito. Mas precisa de luta." |
| **Derrotismo** | Desmotiva | "Não adianta, tudo vai piorar." | "A luta continua. Sempre continua." |
| **Neutralidade excessiva** | Não engaja | "Há argumentos dos dois lados." | "Você escolhe. E a escolha tem preço." |
