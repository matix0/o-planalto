# Política de Citações

## Regra

**Nunca inventar.** Toda afirmação técnica deve ser citada com `arquivo:linha` ou marcada como `[não verificado]`.

## Formato

| Tipo | Formato |
| :--- | :--- |
| Arquivo local | `docs/13_ARQUITETURA_TECNICA.md:126` |
| URL | URL completa |
| Não verificado | `[não verificado]` |

## Verificação

- Conferir no código as afirmações dos agentes.
- Amostragem de 5 citações por plano.
