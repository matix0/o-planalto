# Política de Verificação

## Regra

**Conferir no código as afirmações dos agentes.**

## Como Fazer

1. Agente afirma X.
2. Verificar X no arquivo citado.
3. Se não encontrar, marcar como `[não verificado]`.
4. Se encontrar, confirmar.

## Amostragem

A cada plano, verificar 5 afirmações aleatórias.
