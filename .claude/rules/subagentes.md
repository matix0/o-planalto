# Política de Subagentes

## Regras

| Regra | Descrição |
| :--- | :--- |
| **Máximo 3 em paralelo** | Trabalhos maiores em ondas |
| **Notas incrementais** | Salvar progresso em arquivo desde o início (`.claude/notas/`) |
| **Retorno ≤ 400 palavras** | Com `arquivo:linha` ou URL |
| **Não usar para 1-2 arquivos** | Fio principal resolve |
| **Aprovação do PO** | Fora de plano, pedir aprovação |

## Modelos

| Papel | Modelo |
| :--- | :--- |
| GP, GF, UX, DEV, QA, TA, SFX, AIW | Sonnet |
| GD, PSI, ARQ, ECO | **Opus** |
| Fio principal | Opus 5.5 |

## Quando NÃO Usar

- Ler 1-2 arquivos conhecidos
- Edições pequenas
- Tarefas que o fio principal resolve

Detalhes dos 12 papéis: `gestao/equipe.md`.
